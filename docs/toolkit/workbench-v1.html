rotating-snowflake key · 87 symbols · live cryptanalysis

Key grid

Arm = orientation, ring = arc count. A 45° turn keeps each letter in its ring — that is why ring is invariant.

Transform

Solver

Simulated annealing over symbol→letter maps, scored with English trigrams. Any bijective relabelling of the 24 symbols is absorbed by the solver, so only rotation and reading order change the answer.

Ciphertext

Encipher  plaintext → symbols

Encipher applies the rotation (+k·step); decipher undoes it (−k·step). Same key, same schedule, opposite sign — the round-trip test proves they are exact inverses.
